# master-thesis# 非對稱九子棋之讓子勝率分析與玩家評分系統

國立清華大學資訊工程學系碩士論文研究

## 研究簡介

本研究探討非對稱九子棋在不同讓子條件與玩家強度下的勝率變化，
並建立讓子勝率矩陣，以分析不同遊戲設定下的平衡程度。

研究進一步依據勝率矩陣設計玩家關卡與評分機制，
使不同程度的玩家能透過預測勝率進行較公平的配對。

## 研究內容

- 建立不同 AI 強度與讓子條件的實驗配置
- 進行自動化 AI 對戰與勝率資料蒐集
- 建立讓子勝率矩陣
- 設計玩家關卡與評分／配對機制
- 分析並證明九子棋 3 對 4、3 對 3 殘局的相關邊界條件

## 程式與研究環境

- C++
- Automated self-play simulation
- Statistical win-rate analysis

## 關於原始九子棋程式

本研究使用既有開源九子棋遊戲與 AI 程式作為基礎，
並依研究需求修改及擴充部分功能，包括實驗參數設定、
自動對戰流程與資料蒐集等。

原始遊戲引擎及 AI 並非由本人從零開發。

由於原始專案的授權條款包含額外使用限制，
本 repository 不重新散布完整的原始遊戲與 AI 程式碼。
